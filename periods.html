Period rooms

A museum builds period rooms so you can stand inside a century instead of reading about it. These twenty do that for the interface — each borrowing the palette, typography, and composition of a movement the archive already documents.

Composition is the point. A Byzantine icon is symmetrical and arch-topped; a manuscript runs two justified columns with a gloss in the margin; De Stijl has no image block at all because the layout is the artwork. Same record in all twenty — different architecture each time.

They run chronologically: 530 BC → 1967. Pick by number; mixing is fine.
I’ll build the chosen direction as the live site.
Pure CSS — procedural gradients, clip-paths, blend modes, SVG turbulence. No images, no libraries, no font downloads.
Faces already on the machine: Optima (cut from Roman inscriptions), Hoefler Text, Baskerville, Iowan Old Style, Didot, Snell Roundhand, Copperplate, Futura (the Bauhaus face), Helvetica (the Swiss one), Impact.
Live archive: dig-archive.vercel.app — 500 records across these same movements.

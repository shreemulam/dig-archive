Period rooms

A museum builds period rooms so you can stand inside a century instead of reading about it. These twenty do the same thing for the interface: each one borrows the palette, typography, and compositional logic of a movement the archive already documents.

They run in chronological order — 530 BC to 1967 — so scrolling the page is itself a walk through art history. Every specimen shows the same record, and each names the record it descends from, because the design and the content are the same subject.

Pick by number. Mixing is legitimate — “03 for the record card, 19 for the map”.
I’ll build the chosen direction as the live site.
All twenty are pure CSS — procedural gradients, blend modes, SVG turbulence. No images, no libraries, no font downloads.
Type is drawn from faces already on the machine: Optima (cut from Roman inscriptions), Hoefler Text, Baskerville, Iowan Old Style, Futura (the Bauhaus face), Helvetica (the Swiss one), Copperplate, Snell Roundhand, Impact.
Live archive: dig-archive.vercel.app — 500 records across these same movements.

Twenty ways to dream the archive

The archive currently speaks in one voice: terminal grids, acid green, industrial registration marks. Useful, cold, legible. These twenty propose the opposite instinct — that a place built for falling into should feel like falling.

Every specimen renders the same record so the palettes, typography, and texture can be judged against each other rather than against different content. Each is a complete world: its own type pairing, its own material, its own relationship to light.

Pick by number. Say one, or mix — “12 for the card, 6 for the map”.
I’ll build the chosen direction as the live site.
All twenty are buildable with CSS alone — no image assets, no libraries.
Textures are procedural: gradients, blend modes, SVG turbulence. Type is drawn from faces already on the machine, so nothing waits on a font CDN.
Current site for reference: dig-archive.vercel.app — 500 records, direction 20 is its dreamed version.

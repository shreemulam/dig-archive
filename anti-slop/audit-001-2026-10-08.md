# antislop audit 001 — DIG.ARCHIVE

Date: 2026-10-08 · Mode: AFTER · Scope: dig-archive.vercel.app (index.html, records.json, cases.json)
No files were modified. Approve findings by number; numbers not mentioned stay untouched.

Direction note: there is no `DESIGN.md` yet, so findings 8, 9, 10, 12, 13 are all "the reason is not
written down" rather than "the choice is wrong". Writing the direction may close them without a code change.

---

## HIGH — Hard Gate (absolute, no exceptions)

**1. R-02 — 3,152 em dashes across all 500 records.**
Every record's `fact`, `more` and connection `note` is agent-written text, and the de-slop pass in August
only covered `index.html`. Measured: 3,152 occurrences, present in all 500 records.

**2. R-02 — 3 em dashes in shipped interface and shared text.**
The RSS feed title (`DIG.ARCHIVE — new acquisitions`), the header placeholder `REC —/—` shown until data
loads, and the Daily Dig share string users paste into social posts.

**3. R-32 — The product's primary interaction is mouse-only.**
Constellation nodes, atlas nodes, gallery thumbnails, trail crumbs, the case-file strip, Dig of the Day and
Resume are click-handled `div`/`span` elements with no `tabindex` and no key handler. Tab order on a record
page reaches 19 native controls and zero of these. Opening a connection, the core action of the archive,
cannot be done from a keyboard. Node clicks also route through `elementFromPoint` hit-testing rather than
element listeners, so adding `tabindex` alone will not fix it.

**4. R-03 — 11 of 25 visible controls at 390px are under the 44px tap minimum.**
Trail crumbs 63×23, NEXT FACT 84×15, discourse source links 89×14, Dig of the Day row 350×28,
PLAY TODAY'S DIG 187×38, back button 105×34. (Horizontal overflow measured 0px, which passes.)

**5. R-27 — The archive has no loading state.**
`records.json` is roughly 2MB. Until it resolves the header reads `REC —/—` and the dossier is blank with no
indication anything is happening. The failure path writes a single line into the ticker, which is easy to miss.
DIG HERE already does this correctly (Triangulating / nothing found / denied / failed), so the pattern exists.

## MEDIUM — Purpose-Gate (technique allowed, written reason required)

**6. R-19 — Decorative status dot.**
The brand mark's dot runs `blink 2.4s steps(2) infinite` and marks no state. antislop-ui names this pattern
directly: system-status vocabulary used as decoration.

**7. R-19 — Endless glow loop on the globe.**
`globePulse 4.5s ease-in-out infinite` runs with no user trigger and nothing behind it.
(`hintPulse` and `nudgePulse` are exempt in my reading: both mark real state and both self-terminate.)

**8. R-07 — Page-wide background grid.**
A 72px grid sits behind every view. It plausibly serves the archive/blueprint identity, but no reason is written.

**9. R-06 — Monospace as the interface voice, plus wide-tracked uppercase.**
IBM Plex Mono carries nearly all UI text, and labels run at `letter-spacing` .14em to .3em in uppercase
throughout. Both are listed tells; both are defensible here; neither has a written reason.

**10. R-13 — Glow past its dose cap.**
Globe halo, hint pulse, title `text-shadow: 0 0 24px`, install bar, node hover shadow. The cap is 1-2 elements.

**11. R-08 — Arrows as a default affordance.**
`▸` appears on 11 controls, `↗` on 4, `→` elsewhere. Decoration rather than a direction cue on most.

**12. R-29 — Ten color tokens, five of them accents.**
acid, pink, ice, amber, bone against a cap of 2-3 core + 1 accent. Four of the five are the connection-type
legend and genuinely carry information, which is a strong defence, but it is not written anywhere.

## LOW — Quality Locks (consistency)

**13. R-21 — Dark forced, no toggle, reason unwritten.**
An archive that displays artwork has a real reason to be dark, the way a gallery does. It is not recorded, and
DIG HERE deliberately sends people outdoors, where a dark interface is at its worst.

**14. R-32 (quality side) — Focus rings are the browser default.**
Measured as Chrome's `auto 1px` via `:focus-visible`. Nothing was suppressed, so this is not a Hard Gate
failure, but a 1px UA ring is weak on near-black and off-system against the acid palette.

**15. R-25 adjacent — Control boundaries at 1.36:1.**
`--line` (#2a2c20) against the ground. Correct for decorative hairlines, but it is also the only visible
boundary on cards, chips and the map legend. WCAG 2.1 asks 3:1 for the boundary of a control.

**16. R-31 — No written reason exists for any major decision.**
There is no `DESIGN.md`, so the keystone rule has nothing to check against. This is the root cause of 8, 9,
10, 12 and 13.
